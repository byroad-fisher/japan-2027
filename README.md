# Japan 2027

Mobile-first static trip planner for a 10-day Japan trip from Dublin after 12 June 2027.

## Current route
Tokyo (3) → Kyoto (3) → Hiroshima (1) → Osaka (2) → Tokyo (1)

## Stack
Plain HTML/CSS/JS, Leaflet and OpenStreetMap. No paid map API or backend.

## Status
Early planning version. Exact 2027 flights, train timetables, event calendars, accommodation, attraction hours and prices must be rechecked before booking.

## JR Pass
Working strategy: compare a 7-day nationwide JR Pass activated on Day 4 against point-to-point fares before purchase. Current prices/rules are planning references only.

## Deployment
Designed for GitHub Pages from the repository root on `main`.
